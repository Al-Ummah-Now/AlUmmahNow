# Injection audit for the admin apps and workers

This table records the input boundaries inspected in this change and the checks used to verify them. AI tests use fixtures and mocked bindings. Network tests use local services or mocked fetches.

| Component | Input | Risk | Admin API status notifications | Admin-entered webhook URL and stored destination read by the queue consumer | Unsafe scheme, local hostname, nonstandard port and redirects | Fixed. The URL is validated at registration and again at send time and the delivery fetch handles redirects manually. | `apps/admin-api/test/status-notify.test.ts` |
| Status | Verification |
| --- | --- | --- | --- | --- |
| Theme packages | ZIP file headers, names, offsets and file data | Path traversal, aliases, non-regular entries, overlapping metadata, excess decompression | Fixed. The reader bounds the archive, entry count and total decompression. It checks relative paths, duplicates, file modes, header agreement and CRC. | `packages/theme-packages/test/package.test.ts` |
| Admin API themes | `POST /api/themes/import`, `id`, `newId`, `theme.json` and assets | Untrusted metadata or active content stored in a draft, unbounded request bodies | Fixed. The API limits the streamed upload, checks the package schema and checks each file and the aggregate asset size before creating the draft. | `apps/admin-api/test/theme-packages.test.ts` |
| Admin API themes | Draft asset read, write, delete and published asset delivery | R2 path selection, SVG execution, response content type | Fixed. Reads and writes restrict asset names and SVG delivery adds a sandbox policy. Individual uploads and ZIP imports enforce the same asset checks. | `apps/admin-api/test/theme-packages.test.ts` |
| Admin API themes | `GET /api/themes/:id/export` filename and version | Header injection | OK. The export reads an existing theme ID and accepts the draft or a numeric version string. The filename is assembled from those fields. | `apps/admin-api/test/theme-packages.test.ts` |
| Theme packages | CSS-valued schema fields, token references, asset paths, SVG markup | CSS rule or resource injection, executable SVG, external requests | Fixed. CSS values reject comments, raw URLs and quoted image sources. Asset references use the package file grammar. SVGs accept passive elements and local paint references. | `packages/theme-packages/test/package.test.ts` and `themes:check` |
| Admin web theme builder | Live editor state and SVG art read by the preview | Rendering CSS from an invalid draft | Fixed. The preview gates CSS and asset fetching on validation, checks SVG before compiling it, and disables scripting in its iframe. | Theme validator regression tests and admin web type-check |
| Admin web site theme | Published theme metadata from the admin API | SSRF via CSS resource URLs | Fixed. The web app builds the CSS request from the configured admin API origin and validated package ID and version. Neither theme request follows redirects. | `apps/admin-web/test/shell.test.ts` |
| Admin API search | Error search, moderation queue, staff names, contact inbox and invites | SQL and LIKE pattern injection | OK. The reviewed predicates bind parameters and escape wildcard characters in literal searches. | `apps/admin-api/test/errors.test.ts`, `contact-inbox.test.ts` and `audit-feed.test.ts` |
| Admin API contact intake | Sender email, message and captured page URL | Header injection or untrusted navigation in the inbox | OK. The contact parser bounds text and validates email. The page URL must have a supported scheme and platform host. React renders the message as text. | `apps/admin-api/test/contact-submit.test.ts` and `contact-inbox.test.ts` |
| Admin web authentication | Callback state, return path and refresh continuation | Open redirect | OK. The login flow checks a same-origin return path before using it. | Admin web login and passkey tests |
| Cost monitor | Queue work version, job kind, timestamp and calendar day | Coercion of an unrecognised job and malformed time windows | Fixed. Job names require strings from the declared set and date inputs use the supported format and range. | `apps/cost-monitor/test/costs.test.ts` |
| Cost monitor | Scheduled collection and provider usage replies | GraphQL and SQL injection | OK for the reviewed collection queries. The GraphQL document is constant with separate variables. SQL data values are bound and the product cost column has two fixed choices. | `apps/cost-monitor/test/costs.test.ts` |
| Log service | `POST /log` and `POST /log/batch` | Filesystem path selection, forged log records | Fixed. Single and batch writes use the same app name and level validation and encode control characters on one physical line. | `apps/log-service/src/index.test.ts` |
| Log service | `GET /logs/:appName`, snapshots, SSE and viewer | File path selection, HTML injection | Fixed. Direct reads check the filename grammar. Aggregate reads select among files already enumerated in the log directory and SSE writes JSON. The viewer inserts entry fields as text. | `apps/log-service/src/index.test.ts` and viewer source review |
| Logger | Node file logging and structured console entries | Log splitting, local filename injection | Fixed. File output validates the app name and encodes controls. Console output remains a structured object. | Logger build and log-service record regression |
| MCP log server | Tool filters for `get_logs`, `watch_logs`, `search_logs`; log text returned by the service | Query parameter injection | OK for URL construction. Tool names dispatch through a switch, filters are encoded with `URLSearchParams`, and search text is passed to a substring comparison. The host comes from process configuration. | MCP build and source review |
| Media worker | Queued live recording URL and container VOD requests | SSRF, redirects and reads outside the recording | Fixed. Initial playback uses an HTTPS delivery host. Outbound VOD fetches disallow redirects and require regular relative path segments. | `apps/media/test/live-review.test.ts` |
| Media worker | Internal job path/commands, private rendition and download paths | R2 selection and unauthorised mutations | OK for the reviewed key boundaries. Internal job endpoints require a shared key and a valid video ID. Private media uses signed path claims and constrained keys. | `apps/media/test/internal-jobs.test.ts` and media suite |
| Processor review | Video thumbnail and image-review queue URLs | SSRF and redirect following from image downloads | Fixed. Both review paths use a single fetcher with an HTTPS delivery allowlist and disallow redirects. | `apps/processor/src/__tests__/review-consumer.test.ts` |
| Processor moderation | Text passed to the review classifier and classifier responses | Content treated as instructions, incomplete verdict accepted | Fixed. Policy text is wrapped in a data field with escaped delimiters. Review scores cover the configured categories and unrecognised Llama Guard output takes the error path. | `apps/processor/src/__tests__/review-consumer.test.ts` and `moderation-units.test.ts` |
| Processor push | Stored WNS channels and Web Push subscriptions | Server request forgery, credential forwarding via redirects | Fixed. Outbound senders verify provider HTTPS hosts and disallow redirects. | `apps/processor/src/__tests__/push-senders.test.ts` and `push-webpush.test.ts` |
| Scheduler | Scheduled R2 documents and `POST /failed/retry` | Document selects a different video or schedule key | Fixed. The video ID and timestamp must agree with the key read before the worker publishes or retries. | `apps/scheduler/test/scheduler.test.ts` |
| Short links | Target path and forwarded query parameters | Scheme or destination injection | OK. The path identifies a typed entity or the home page. The worker chooses a configured origin, encodes IDs and forwards only the share parameter allowlist. | `apps/short-links/test/routes.test.ts` |
| Status | `/en/*` canonical redirect | Path treated as an external destination | Fixed. The worker sets a pathname on its own origin. | `apps/status/test/subscriptions.test.ts` |
| Status | `/subscribe`, `/subscribe/confirm`, `/unsubscribe` form and token inputs | SQL injection and HTML injection | OK for the reviewed form fields. Email and token shape are checked, D1 operations bind values and the renderer escapes text. | `apps/status/test/subscriptions.test.ts` |
| Status | Cron playback probe data from the public videos API | SSRF or media path injection | Fixed. R2 IDs and revisions use the media key grammar. Bunny probes accept only the configured HTTPS delivery hosts and use manual redirects. | `apps/status/test/status.test.ts` |
| WebSocket server | `authenticate`, `subscribe`, `unsubscribe`, `message`, `ping`, `heartbeat` | Oversized or malformed frames, unstructured channel names, missing data, unauthorised subscription or publish | Fixed. Client messages use a bounded discriminated schema. Existing token expiry, public feed exceptions, private channel ownership and server-only channel rules remain covered. | `apps/websocket-server/test/websocket.test.ts` and `admin-live.test.ts` |
| WebSocket server | Worker and DO fan-out, ticket, view, live viewer and QoE routes | Untrusted fan-out and access to internal topics | OK for the reviewed auth boundary. Internal routes verify the key before dispatching, and topic-directory calls use a service binding. | `apps/websocket-server/test/internal-key.test.ts`, `tickets.test.ts` and `topic-router.test.ts` |
| Shared types | Media key grammar, Bunny library hosts and short-link target parsing | Unsafe handoff between workers | Fixed for CDN host selection. Shared key and target parsing remain the input contracts reused by the callers above. | Media, status and short-links tests |
