# Injection Security Audit — `apps/web`

Audit date: 2026-11-28
Scope: `apps/web` (Next.js 16 App Router on OpenNext / Cloudflare Workers) — all pages, Route Handlers, Server Actions, middleware, forms, URL/search params, cookies/headers, embeds, and UGC rendering surfaces.

Shared hardening module: [`apps/web/src/lib/security/safe-input.ts`](../../apps/web/src/lib/security/safe-input.ts) (protocol allowlists, same-origin path validation, strict DNS/Host header validation, path-segment encoding, header/log sanitization, and `valibot` schemas). Note: `apps/web` uses `valibot` (`^1.5.0`, already a direct dependency in `apps/web/package.json`) rather than adding a duplicate schema library.
