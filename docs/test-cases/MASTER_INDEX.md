## Execution Guidelines

### Running All Tests
```bash
# Run all test cases
pnpm test:e2e:all

# Run by category
pnpm test:e2e:video-platform
pnpm test:e2e:authentication
pnpm test:e2e:bilingual
# ... etc
```

### Running Individual Tests
```bash
# Run specific test case
pnpm test:e2e --grep "TC-VID-001"

# Run by priority
pnpm test:e2e:critical
pnpm test:e2e:high
```

### Test Environment Setup
```bash
# Setup test environment
pnpm test:setup

# Cleanup test data
pnpm test:cleanup

# Generate test report
pnpm test:report
```
